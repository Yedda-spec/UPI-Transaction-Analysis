# UPI Transaction Analysis | Power BI

## 📌 Project Overview

This project presents an interactive Power BI dashboard for analyzing UPI (Unified Payments Interface) transactions. It allows users to explore transaction data and understand patterns through data visualization.

## 🎯 Project Objective

The objective of this project is to use Power BI to transform UPI transaction data into an interactive dashboard that makes transaction information easier to explore and understand.

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)

## 📊 Dashboard

The dashboard was created using Power BI to visualize and explore UPI transaction data.

**Key features:**

* Interactive data visualizations
* Transaction data exploration
* Dashboard-based analysis

## 📁 Project Files

* `upi TRANSACTION.pbix` — Power BI project file containing the dashboard.

## 🚀 How to View the Project

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the interactive dashboard.
